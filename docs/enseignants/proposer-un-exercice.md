# Proposer un exercice

Vous avez un exercice qui fonctionne bien avec vos élèves ? Proposez-le. **Vous n’avez rien à programmer ni à installer**, et vous n’avez pas besoin de connaître le format des fichiers techniques.

## 1. Remplir la fiche

Dans Wamon, cliquez sur **Proposer un exercice**. La fiche se remplit comme un sujet de TP :

| Rubrique | Ce qu’on attend | Exemple |
| --- | --- | --- |
| Titre | Un titre court | Dosage du vinaigre du commerce |
| Niveau | Une ou plusieurs classes | Terminale |
| Énoncé | Le texte donné aux élèves | On dose 10,0 mL de vinaigre dilué dix fois par de la soude… |
| Données | Une ligne par valeur : nom, symbole (facultatif), valeur, unité | Concentration de la soude, Cb, 0,10, mol/L |
| Ce que la classe doit trouver | La grandeur cherchée et la réponse attendue | Concentration du vinaigre dilué, Ca = 0,142 mol/L |
| Correction | Le raisonnement et le calcul | À l’équivalence, Ca × Va = Cb × Ve… |
| Expérience à montrer | Ce que la classe doit voir | Avec la phénolphtaléine, la solution devient rose vers 14,2 mL |

L’**aperçu** à droite montre l’énoncé tel qu’il sera projeté. Votre brouillon est enregistré dans votre navigateur : vous pouvez fermer la page et revenir plus tard.

## 2. L’envoyer

Choisissez le moyen qui vous convient :

- **Envoyer sur GitHub** : un formulaire s’ouvre, déjà rempli. Il faut un compte GitHub (gratuit, une adresse e-mail suffit). C’est la voie la plus rapide, car l’équipe y suit toutes les propositions.
- **Partager par WhatsApp** : le texte de la fiche est prêt à être envoyé à un membre de l’équipe.
- **Copier le texte** : collez-le dans un e-mail.
- **Télécharger la fiche** : un simple fichier texte, à envoyer comme vous voulez.

Ce que vous envoyez sur GitHub est public. N’y mettez jamais d’informations sur vos élèves.

## 3. Et ensuite ?

1. Un membre de l’équipe vérifie que l’exercice peut devenir une expérience avec le matériel déjà simulé, ou s’il faut créer une nouvelle animation.
2. Un autre professeur relit le calcul, les unités et la sécurité des manipulations.
3. L’exercice est ajouté à Wamon et vous êtes prévenu. Votre nom apparaît dans les remerciements si vous l’avez indiqué.

Vous pouvez suivre l’avancement de votre proposition sur GitHub, dans la liste des tickets marqués [`exercice`](https://github.com/Gecnos/wamon/labels/exercice).

## Les exercices les plus faciles à ajouter

Ceux qui utilisent une expérience déjà présente dans Wamon :

- un **dosage** d’un acide par la soude, avec un indicateur coloré ;
- une **dilution** ou une **dissolution** dont on compare la teinte à un témoin.

Les autres idées sont aussi les bienvenues : elles demandent simplement plus de travail, et c’est ainsi que Wamon s’enrichit.
